# 현재 상태와 남은 작업

## 현재 구현

- 디렉터리 일괄 CLI, 파일별 격리, 기본 파일60초/전체540초, JSON 출력·원본 위치 근거.
- 일곱 판정 규칙과 함수별 흐름 설명. 현재 지원 경계는 [분석 안내](EXPANDED_RULES.md), 출력 해설은 [REPORTING](REPORTING.md).

- [검증 자료](experiments/README.md)에 실제 기록을 보존. 비공개 성능 보장은 아님.

## 최근 정리

docs를29개에서11개로 줄였다. 중복 계획서·철회 기능 설명·개발 중간 결과는 로컬 `results/docs-archive-20260919-235143/`에 원본 해시를 확인해 보관했다. Git에 포함하는 문서는 현재 사용법·원리·출력·제출 절차와 대표 검증 근거로 한정했다. 상세 일지는 보관본과 Git 이력에서 확인한다.

이번 정리는 문서·문서 참조만 변경했다. 분석 소스·테스트·Dockerfile·컴파일러·의존성·고지115개 파일의 해시가 기존 검증본과 동일함을 확인했다. Markdown 링크53개·HTML 링크81개 누락 없음, HTML JavaScript 문법과 diff 공백 검사도 통과했다. 분석 테스트를 다시 실행한 것은 아니다. commit/push는 수행하지 않았다.

## 남은 작업

1. 변경 목록을 검토하고 최종 commit을 만든 뒤 push한다.
2. 최종 고정본으로 이미지를 준비하고 주최 측 방식에 맞춰 전달한다. [제출 절차](SUBMISSION.md)에서 commit·이미지·tar 식별값을 기록한다.
3. 바이너리 전달에 관한 고지 수집 범위와 대응 소스 제공은 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)를 참고한다.

사용자의 코드 설명·실습 완료는 아직 확인하지 않았다. 기술 검증과 사용자의 이해 확인을 구분한다.
